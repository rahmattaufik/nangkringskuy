# 🔥 NANGKRING SKUY 45 — BBQ, Street Food & Hangout Space

> Official Website & Smart POS System for **Nangkring Skuy 45 (EST. 2026)** — Pasar Baru, Kota Manna, Bengkulu Selatan.

---

## ✨ Fitur Utama (Key Features)

1. **Digital Ordering System (Dine-In Table Order)**:
   - Pelanggan dapat memilih nomor meja (Meja 01 - 20) via scan QR Meja atau URL query (`?meja=05`).
   - Input Nama Pemesan / Customer otomatis dengan validasi cerdas & auto-remember.
   - Keranjang pesanan real-time & Digital E-Receipt ber-QR Code resmi.
   - Terintegrasi langsung dengan WhatsApp Konfirmasi Kasir (**085184320877**).

2. **Master Database & Analytics (`NangkringDB`)**:
   - Master data katalog menu BBQ, makanan utama, snacks, signature coffee, dan fresh drinks di `database.json`.
   - Data 20 Meja Kafe (Indoor AC, Outdoor Smoking, VIP Sofa, Outdoor Bar, Outdoor Garden).
   - Export Rekap Laporan Penjualan ke format `.CSV` (Microsoft Excel / Google Sheets).
   - Backup & Restore Database Full `.JSON`.
   - Konektor Cloud Real-time (Supabase / Firebase Ready).

3. **Portal Kasir & POS Dashboard**:
   - Dashboard kasir dengan login PIN (`1234`).
   - Pemantauan pesanan meja pelanggan real-time.
   - Transaksi kasir langsung (Manual Bill & Direct Order).
   - Generator & Cetak QR Code Meja (1-10 / 1-20) siap cetak di stand akrilik meja.
   - Kalkulator pembayaran tunai, kembalian, QRIS, dan debit transfer.

4. **Reservasi & Booking Acara**:
   - Formulir reservasi meja & gathering komunitas langsung terhubung ke WhatsApp kafe.

## 🛠️ Tech Stack & Design

- **Core**: HTML5, Vanilla JavaScript (ES6+), Vanilla CSS3.
- **Visual & Theme**: Dark Mode (#111111) with Vibrant Fire Orange (#FF6B00), Flame Red (#FF3D00), & Yellow (#FFC107).
- **Fonts**: Bangers (Headline), Lilita One (Subheadline), Bebas Neue (Navigation), Poppins (Body Text).
- **Libraries**: FontAwesome 6, QRCode.js.
- **Deployment**: 100% Vercel Ready & Static Hosting Ready.
